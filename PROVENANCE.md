# Project provenance

Brahma is an adapted edition of Entity Intelligence API / Argus by
Prakhar Anand, from https://github.com/Prakharanand000/supplier-intelligence-api.
The source snapshot is commit `5559b1f1d914e79682b4b625a084359b061cbb31`.
The full upstream Git history is retained in this checkout.

The requester states that the original author has granted permission to reuse
and modify the project. That private permission has not been independently
reviewed. No repository-wide open-source license was supplied with this snapshot;
do not infer a general right to redistribute it beyond that permission.

This edition adds the Brahma visual identity, a rebuilt responsive application
shell, local Lucide assets, externalized frontend modules, clearer sample/live
states, frontend reliability improvements, and additional regression checks.
The original entity-resolution, source adapters, risk engine, strategy workflows,
and API contracts remain the foundation. See `docs/UPSTREAM_README.md` for the
original documentation and Git history for implementation attribution.

AI coding tools assisted the Brahma redesign, integration, and testing. This
document records provenance; it is not a customer pitch or an authorship claim.

Lucide icons are distributed under the ISC license. Their license is retained
at `static/vendor/LUCIDE-LICENSE.txt`.
